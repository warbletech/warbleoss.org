# Contributing to warbleoss.org

Thanks for helping improve the Warble OSS site.

## Quick start

1. Fork the repository and create a branch from `main`.
2. Edit `index.html`, `404.html`, or files in `assets/`.
3. Preview locally with `python3 -m http.server 8080` and open
   <http://127.0.0.1:8080>.
4. Open a pull request with a short description and, for visual changes, a
   screenshot.

## Guidelines

- Keep the site static: plain HTML and CSS, no build step.
- Follow the speaking rules in [README.md](README.md). Do not claim CNCF or
  Linux Foundation project status before acceptance.
- Link to repositories under `github.com/warbletech`.
- Check links before submitting (for example with
  [lychee](https://github.com/lycheeverse/lychee)).
