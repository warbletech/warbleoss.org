# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Email <security@warblecloud.com> with:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- affected URLs, components, or versions.

We prefer coordinated disclosure and will acknowledge your report, keep you
updated on progress, and credit you unless you ask to stay anonymous.

## Scope

- This repository and the site at <https://warbleoss.org>.
- The public demo MCP server at <https://mcp.warbleoss.org> (read-only,
  demo-grade). Report abuse to the same address.

For product repositories (ShrikeOps, Heron Ops, Starling EX Community), see the
`SECURITY.md` in each repository or in
[warble-army](https://github.com/warbletech/warble-army).
